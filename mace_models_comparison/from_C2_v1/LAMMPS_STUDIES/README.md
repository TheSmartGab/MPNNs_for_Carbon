# LAMMPS Studies

This directory contains the studies ran with LAMMPS using the trained from_C2_v1 model.
The most time-consuming one is the strain-stress that lead to the Arrhenius analysis for the 5_5 system (100 atoms) for the breaking rate under tensile strain along the zigzag direction.

The bilayer rotation studies have been left incomplete, in particular, I did not carry out the studies with PBC.
The graphene bilayer translations were devisive to chose this model over the others.
