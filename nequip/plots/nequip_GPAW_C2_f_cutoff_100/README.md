# NequIP GPAW C2 f_cutoff 100 Plots (`plots/nequip_GPAW_C2_f_cutoff_100`)

This directory contains generated plot outputs and performance visualizations for NequIP models trained with a force cutoff of 100 eV/Å on C2 (diatomic carbon) configurations validated against GPAW reference calculations.

## Contents:

Generated visualization files for:
- NequIP C2 model energy and force error distributions
- Force cutoff sensitivity analyses (f_cutoff = 100 threshold)
- Parity plots comparing NequIP vs GPAW predictions for dimer potentials

## Usage:

These plots are generated by the `src/nequip/metrics/plot_nequip.py` scripts, using comparison data from `nequip/GPAW_pair_scan_gridsearch_offset*` configurations and DFT references from `gpaw_testing/C2/`. The f_cutoff = 100 parameter indicates a maximum force threshold used during model training or evaluation to filter out high-stress configurations.
