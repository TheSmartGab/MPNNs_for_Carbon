# NequIP Graphene MLIP Plots (`plots/nequip_models_GRAPHENE_MLIP`)

This directory contains generated plot outputs and performance visualizations for NequIP (Neural Equivariant Interatomic Potentials) models trained on the GRAPHENE_MLIP dataset. These plots show model performance metrics, error distributions, and comparison against DFT reference calculations.

## Contents:

Generated visualization files for:
- NequIP graphene model energy and force RMSE/MAE distributions
- Parity plots comparing NequIP predictions vs GPAW/DFT references
- Hyperparameter sensitivity analyses for 2D carbon ML potentials

## Usage:

These plots are generated by the `src/nequip/metrics/plot_nequip.py` and `src/nequip/metrics/results.py` scripts, using comparison data from `nequip/GRAPHENE_MLIP/` configurations and DFT references from `gpaw_testing/graphene_relax/`.
