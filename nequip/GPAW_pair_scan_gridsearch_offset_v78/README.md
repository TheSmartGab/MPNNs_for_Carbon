# NequIP GPAW Pair Scan Gridsearch with Offset Corrections (`nequip/GPAW_pair_scan_gridsearch_offset_v78`)

Study on the variance of model prediction.
The same nequip model architecture (v78 from the hyperparameter gridsearch) is kept fixed, 100 different trainings are carried out on the dimer configurations.
Then, errors on the dimer energy and forces are studied as a function of the interatomic distance.
