# Dataset Requests (`datasets/requests`)

This subdirectory contains utilities for requesting, retrieving, and processing data from external materials science databases and APIs. These scripts automate the collection of DFT calculation results, crystal structures, and molecular dynamics trajectories from public repositories to build comprehensive training datasets for machine learning interatomic potentials.

This would have been more usefull if the metadata structure were consistent across datasets.
Ultimately, I used curated datasets
