# Dataset Size Studies (`DATASET_SIZE_STUDY`)

This directory contains experiments and configurations studying model performance as a function of training dataset size. These studies help determine the scaling behavior of machine learning interatomic potentials (MACE, NequIP) with respect to training data quantity.

NEW_SPLIT refers to the balanced split of the GAP_2020 dataset balancing cathegories in the training, validation and test splits under DATASETS/GAP2020/config_types/NEW_SPLIT
